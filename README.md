# 🎓 TutorTrack – Web-Based Tutoring Platform

A web platform connecting Sri Lankan A/L students with qualified tutors for academic support.

## 🔑 Features

- Tutor-student profile matching
- Secure login and authentication APIs
- MongoDB-based profile and session storage
- Responsive frontend integration

## 🛠️ Tech Stack

- Node.js  
- React  
- MongoDB  

## 🧪 How to Run

1. `npm install` (backend & frontend)
2. Configure `.env` for DB & JWT
3. Start backend: `npm run dev`
4. Start frontend: `npm start`
